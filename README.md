# AcadMind — Flutter Android

تم توسيع نسخة Flutter لإضافة وظائف تشغيل وإدارة أساسية فوق قاعدة Supabase الموجودة. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub، بحيث يكون `pubspec.yaml` في جذر المستودع.

## بناء APK على GitHub

1. ارفع الملفات إلى فرع `main` أو `master`.
2. افتح GitHub → Actions → `Build AcadMind Flutter APK`.
3. عند نجاح المهمة نزّل `acad-mind-debug-apk` من Artifacts.

الـ APK الناتج حالياً Debug للاختبار. إصدار Google Play يحتاج توقيع Release ثابتاً (keystore) محفوظاً في GitHub Secrets. لم يتم إنشاء keystore أو توقيع إنتاجي داخل هذا المشروع.

## الوظائف التي أضيفت في هذه الجولة

- **إدارة الطلاب:** استعراض الحسابات، تعديل الاسم والهاتف، تعيين السنة والمجموعة والشعبة، وتغيير حالة الحساب إلى نشط/معلق/موقوف. لا يمكن للطالب تعيين نفسه أو ترقية صلاحياته.
- **إدارة المواد:** إضافة مادة وتحديد سنتها، وإضافة محاضرات وفيديوهات YouTube ومجلدات Google Drive، وإخفاء المادة أو تعطيل محتوى منها.
- **إدارة الجدول:** إضافة مواعيد المحاضرات بحسب السنة والمادة واليوم والنوع والوقت والمكان، وإخفاء الموعد بدلاً من حذفه نهائياً.
- **مكتبة AcadMind AI:** رفع ملفات PDF/TXT/DOCX حتى 20MB، ربط الملف بمادة، رفعه إلى Storage الخاص، ثم استدعاء `ingest-knowledge` لمعالجة النص والفهرسة. يمكن أرشفة الملف.
- **المساعد الذكي:** اختيار مادة قبل السؤال للحصول على استرجاع من ملفاتها، وعرض أسماء الملفات والصفحات التي أعادها backend كمصادر.
- **الإعلانات:** نشر إعلان عام، عرض الإعلانات السابقة، وإخفاؤها/إظهارها.
- **التحديثات:** نشر رقم الإصدار والبناء ورابط APK وملاحظات الإصدار وتحديد التحديث الإجباري.
- **الملف الشخصي:** عرض بيانات الحساب والسنة والمجموعة والشعبة، تعديل الاسم والهاتف، وتغيير كلمة المرور.
- **المظهر:** اختيار فاتح/داكن/حسب الجهاز مع حفظ الاختيار محلياً.
- تم استكمال delegates الخاصة بواجهات Flutter المحلية للعربية والإنجليزية.

## وظائف ما زالت تحتاج استكمالاً أو اختباراً

- لا يمكنني تأكيد نجاح `flutter analyze` أو إنشاء APK من بيئة العمل الحالية لعدم توفر Flutter SDK هنا. GitHub Actions هو اختبار البناء الفعلي بعد رفع الملفات؛ أضفت خطوة تحليل Flutter إلى مسار CI.
- واجهة الجدول الحالية تضيف مواعيد على مستوى السنة؛ تعيين المواعيد لمجموعة أو شعبة بعينها يحتاج شاشة نطاق أكثر تفصيلاً.
- إدارة المجموعات والشعب والسنوات نفسها (إضافة/تعديل/تعطيل) لم تكتمل بعد؛ بيانات السنة الأولى وG1/G2 و12 شعبة موجودة في قاعدة البيانات.
- إنشاء حسابات Auth للطلاب يتم من شاشة التسجيل؛ المالك يعيّن السنة والمجموعة والشعبة بعد تسجيل الطالب. لا يوجد إنشاء Auth user مباشرة من التطبيق لأن ذلك يتطلب صلاحية إدارية سرية لا يجوز وضعها داخل APK.
- ميزة **حساب صيف** لم أضع لها سلوكاً افتراضياً؛ الدور موجود في قاعدة البيانات، لكن يلزم تحديد الفرق بينه وبين حساب الطالب قبل تصميم صلاحياته وتجربته.
- التحديث يفتح رابط APK؛ لا ينزّل أو يثبت التطبيق تلقائياً ولا يحذف النسخة القديمة. Android يعرض شاشة التثبيت وفق إعدادات الجهاز.
- الإشعارات تحتاج تجربة على أجهزة فعلية، خصوصاً بعد إعادة تشغيل الهاتف وتغيير إعدادات البطارية والمنطقة الزمنية.
- دعم OTP للهاتف يتطلب مزود SMS، وتأكيد البريد/استعادته يتطلب SMTP مضبوطاً في Supabase.
- النصوص الثابتة في الواجهة ما زالت عربية؛ اختيار الإنجليزية لم يُفعّل قبل ترجمة كل الشاشات ورسائل الأخطاء.
- الذكاء الاصطناعي ومعالجة الملفات يحتاجان ضبط `OPENAI_API_KEY` في Supabase Edge Function Secrets. لا تضع المفتاح في Flutter أو GitHub أو ملف `.env` عام.
- لم تُجر اختبارات تكامل حقيقية للحسابات والمالك والرفع وRAG؛ اختبر هذه العمليات بحساب مالك تجريبي قبل نشره للطلاب.

## إعداد المالك أول مرة

1. أنشئ حساباً عادياً من التطبيق.
2. افتح Supabase SQL Editor للمشروع `skpjvgzxoholaapymvwd`.
3. افتح `supabase/setup/promote_first_owner.sql`، واستبدل البريد الافتراضي ببريد الحساب الذي أنشأته، ثم نفّذ السكربت.
4. سجّل الخروج ثم الدخول من التطبيق. يجب أن تظهر تبويبة **الإدارة**.

لا تستخدم مشروع Supabase الخاص بسَكِينَة؛ AcadMind له مشروع مستقل.

## متطلبات التشغيل

- Flutter stable وAndroid SDK / Java 17.
- الحزم تثبت عبر `flutter pub get`.
- مفاتيح العميل المضمنة هي Supabase Publishable Key فقط. لا تضف `service_role` أو Database password أو OpenAI key إلى التطبيق.
- Supabase migrations وEdge Functions موجودة في مجلد `supabase/`، وتم التحقق من وجود الجداول والسياسات المطلوبة في مشروع AcadMind.
